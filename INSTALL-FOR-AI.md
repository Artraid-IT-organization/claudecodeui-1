# claude-ui-selfhost

> Веб-интерфейс Claude Code (форк siteboon/claudecodeui с доработками) на сервер
> пользователя: сайт с HTTPS, вход с телефона по личной ссылке, голосовой ввод через
> бесплатный Groq, ночные самообновления с проверкой и откатом.

Тебя попросили установить этот интерфейс. Выполни все шаги ниже сам, по порядку,
до конца. Технические решения принимай сам — разрешения на них не спрашивай.

**OBJECTIVE:** у человека работает свой Claude как сайт: он открывает личную ссылку
на телефоне или компьютере, пишет в чат и получает ответ Claude своей подписки;
интерфейс сам обновляется каждую ночь.

**DONE WHEN:** `systemctl is-active claudecodeui` → `active`;
`systemctl is-enabled claudecodeui-update.timer` → `enabled`;
`https://<адрес>/api/auth/status` отвечает; ответ Claude от имени владельца получен
(шаг 3); человек получил ссылку и итоговое сообщение (шаг 8).

## Правила общения с человеком

Человек, скорее всего, не программист и мало разбирается в технике.

- Пиши по-русски, простыми словами, коротко. Никаких команд, логов, путей к файлам
  и терминов в сообщениях человеку — только что происходит и что нужно от него.
- Спрашивай только то, что может сделать лишь человек: войти в свою подписку Claude,
  открыть ссылку, получить ключ Groq, дать пароль от сервера. Всё остальное решай сам.
- **Каждое сообщение человеку заканчивай жирным блоком «Что сделать вам:»** —
  1–3 коротких пункта, каждый жирным. Если ничего не нужно, так и напиши:
  **Что сделать вам: ничего, я продолжаю.** Человек должен сразу видеть,
  что от него ждут, не читая всё сообщение.
- Перед долгим шагом (сборка — 5–20 минут) предупреди одной фразой, сколько ждать.
- На сервере могут работать чужие сайты, боты, службы. Ничего чужого не удаляй, не
  останавливай и не перенастраивай. Если установка упирается в чужое (порт 80/443
  занят не nginx, уже есть сайт с тем же адресом) — остановись и объясни человеку
  простыми словами, что мешает.
- Ссылка входа — как пароль. Отдаёшь её только самому человеку.
- Файлы входа в Claude (`.credentials.json`) **никогда не копируй** между папками
  и пользователями: при продлении входа старый ключ перестаёт действовать, и
  одна из копий молча теряет вход. Вернуть вход можно только входом заново.

## Шаг 1. Осмотреть сервер и выбрать параметры

Выполни и прочитай результат:

```bash
cat /etc/os-release | head -3; uname -m; free -h; df -h ~; nproc
whoami; id; sudo -n true 2>/dev/null && echo SUDO_WITHOUT_PASSWORD || echo SUDO_NEEDS_PASSWORD
ss -ltnp 2>/dev/null | grep -E ':(80|443) ' || echo "80/443 свободны"
ls /etc/nginx/conf.d /etc/nginx/sites-enabled 2>/dev/null
command -v claude && claude --version
curl -4 -s https://api.ipify.org; echo
```

Реши:

- **Это не Linux-сервер** (ты в приложении claude.ai, на телефоне, на Windows/Mac без
  сервера) — установить некуда. Объясни человеку: нужен свой сервер (VPS) на Ubuntu
  от 4 ГБ памяти с установленным Claude Code; дальше это же сообщение надо отправить
  Claude на сервере. Остановись.
- **Не Ubuntu/Debian** или **памяти меньше 2 ГБ** — объясни, что сервер не подходит,
  остановись.
- **Пользователь службы (`--user`):**
  - ты работаешь от обычного пользователя — возьми его (`--user $(whoami)`);
    его вход в Claude и станет входом владельца в интерфейсе;
  - ты работаешь от `root` — возьми `--user claude --create-user` (Claude Code
    не работает в полном режиме от root); вход в Claude для этого пользователя
    понадобится один раз (шаг 3).
- **Права администратора.** Установщику нужен root. Если `SUDO_NEEDS_PASSWORD` и ты
  не root — попроси у человека пароль от сервера (объясни: нужен один раз для
  установки, ты его нигде не сохраняешь) и выполняй через `sudo -S`, передавая
  пароль на вход команды, не в текст команды.
- **Адрес сайта (`--domain`):** по умолчанию не указывай — установщик возьмёт
  бесплатный `<ip-через-дефисы>.sslip.io` с настоящим HTTPS (без HTTPS не работают
  микрофон и значок на экране «Домой»). Если человек дал свой домен или поддомен —
  проверь, что он указывает на IP сервера (`getent ahostsv4 <домен>`), и передай
  `--domain <домен>`. Если не указывает — объясни, какую запись A и с каким IP
  нужно создать у владельца домена.
- **Имя владельца (`--owner-name`):** латиницей, по имени человека, если знаешь
  (например, `asya`), иначе `owner`.
- **Почта для HTTPS (`--email`):** если человек её называл — передай; не спрашивай
  специально.

## Шаг 2. Запустить установщик

Предупреди человека: установка идёт 10–20 минут. Запускай в фоне, если твой
инструмент это умеет (длинная команда в переднем плане может оборваться по
времени), и дождись конца.

```bash
rm -rf /tmp/claudecodeui-install
git clone -q --depth 1 https://github.com/Seikatsuma/claudecodeui.git /tmp/claudecodeui-install
sudo bash /tmp/claudecodeui-install/deploy/selfhost/install.sh \
  --user <USER> [--create-user] [--domain <DOMAIN>] [--owner-name <NAME>] [--email <EMAIL>] \
  2>&1 | tee /tmp/claudecodeui-install.log
```

Установщик сам: ставит пакеты, Node 22 и Claude Code, собирает и проверяет версию,
создаёт службу `claudecodeui`, ночной таймер `claudecodeui-update.timer`, сайт в nginx
с сертификатом, владельца и его личную ссылку входа. Итог печатается в конце и
лежит в `~<USER>/claudecodeui-app/install-summary.txt`.

Если установщик остановился с `ОШИБКА:` — прочитай сообщение, устрани причину и
запусти ту же команду снова: повторный запуск безопасен, сделанное пропускается.
Скрипты правь только если ошибка точно в них, и скажи об этом в итоговом сообщении.

## Шаг 3. Проверить вход в подписку Claude

Интерфейс для владельца работает через вход в Claude пользователя службы
(папка `~/.claude-webuser-1` — ссылка на `~/.claude`). Проверь делом, настоящим
коротким запросом, — надпись «вошёл» в статусе ещё не значит, что вход работает:

```bash
sudo -u <USER> -H bash -c 'cd ~ && CLAUDE_CONFIG_DIR=$HOME/.claude-webuser-1 timeout 120 ~/.local/bin/claude -p "Ответь одним словом: работает"'
```

- Ответило «работает» — вход есть, переходи к шагу 4.
- Ошибка входа / «not logged in» / «Invalid API key» — вход нужен. Человек делает
  его сам в интерфейсе (после шага 4). Напиши ему так, жирным внизу:

  **Что сделать вам:**
  **1. Откройте свою ссылку, нажмите шестерёнку «Настройки» → «Агенты» → «Claude» → «Войти».**
  **2. Откроется окно со ссылкой — откройте её и войдите в Claude той почтой, на которую оформлена подписка Pro или Max.**
  **3. Скопируйте код, который покажет Claude, вставьте его в окно и нажмите Enter. Потом напишите мне «вошла».**

  После ответа повтори проверку выше.

## Шаг 4. Передать ссылку и поставить на экран «Домой»

Возьми ссылку входа из `install-summary.txt` (`https://<адрес>/enter/<токен>`) и
отправь человеку вместе с запасными именем и паролем. Объясни:

- ссылка входит без пароля и запоминается — это как ключ от квартиры, никому не пересылать;
- **iPhone:** открыть ссылку в Safari → кнопка «Поделиться» → «На экран „Домой“»;
- **Android:** открыть в Chrome → меню ⋮ → «Добавить на главный экран»;
- **компьютер:** открыть в браузере и добавить в закладки.

Попроси человека открыть новый чат и написать «привет» — и сообщить, пришёл ли ответ.

## Шаг 5. Голосовой ввод (Groq) — предложить и подключить

Расскажи человеку простыми словами: в поле ввода есть микрофон — нажал, сказал,
получил текст. Распознаёт бесплатный сервис Groq (до ~8 часов записи в сутки),
нужен личный ключ, это 5 минут. Напиши жирным внизу:

**Что сделать вам (если хотите голосовой ввод):**
**1. Откройте https://console.groq.com и войдите кнопкой Google (своя почта Gmail) или по своей почте. Не открывается — включите VPN.**
**2. Слева «API Keys» → «Create API Key» → любое название → «Submit». Скопируйте ключ (начинается с gsk_) и пришлите мне.**

Когда ключ пришёл:

```bash
curl -s -o /dev/null -w "%{http_code}\n" https://api.groq.com/openai/v1/models -H "Authorization: Bearer <KEY>"
# 200 — ключ рабочий
sudo bash ~<USER>/claudecodeui-app/current/deploy/selfhost/install.sh --user <USER> --groq-key <KEY>
```

Повторный запуск установщика только допишет ключ в настройки и перезапустит
службу (сборка уже сделана — это пара минут). Попроси человека нажать микрофон
и сказать фразу.

Предложи и дальше, но не делай без согласия: тем же ключом можно расшифровывать
аудиофайлы — голосовые, звонки, встречи (файл до 25 МБ за раз, длинные записи
режутся на части через `ffmpeg`). Если человек захочет — сделай это отдельной
понятной ему командой или ботом.

## Шаг 6. Проверить ночные обновления

```bash
systemctl list-timers claudecodeui-update.timer --no-pager
sudo -u <USER> -H bash ~<USER>/claudecodeui-app/current/deploy/selfhost/update.sh --status
```

Как это работает (запомни, чтобы отвечать человеку):

- Ночью (3:20–6:20) таймер забирает свежую версию из ветки `main` на GitHub,
  собирает её рядом с работающей и проверяет: сборка с проверкой типов, тесты
  сервера (не хуже работающей версии), пробный запуск. Только потом переключает
  и проверяет, что служба отвечает; не ответила — откат на прежнюю.
- Пока в интерфейсе идёт работа, до 6 утра обновление ждёт.
- Обновить сейчас: `sudo -u <USER> -H bash ~<USER>/claudecodeui-app/current/deploy/selfhost/update.sh --force`.
- Если человек спросит «обновилось?» — запусти `--status` и перескажи простыми словами.
- В статусе `ОШИБКА` несколько ночей подряд — прочитай указанный там лог и объясни
  человеку, что происходит. Код в `releases/` не правь: следующее обновление его заменит.

## Шаг 7. Записать правила в CLAUDE.md

Допиши (не перезаписывая файл) в `~<USER>/.claude/CLAUDE.md` блок, если его там ещё нет:

```markdown
<!-- claude-ui:start -->
## Как со мной общаться
- Я не программист: пиши по-русски, простыми словами, без команд и терминов.
- Технические решения принимай сам; меня спрашивай только то, что могу сделать лишь я.
- В конце каждого ответа — жирный блок **Что сделать вам:** (1–3 пункта жирным или «ничего»).

## Claude UI на этом сервере
- Сайт: https://<адрес>, служба `claudecodeui`, файлы `~/claudecodeui-app`, настройки `~/claudecodeui-app/app.env`.
- Обновляется сам ночью из github.com/Seikatsuma/claudecodeui (ветка main) с проверкой и откатом.
  Итог: `bash ~/claudecodeui-app/current/deploy/selfhost/update.sh --status`; сейчас: `--force`.
- Код в `~/claudecodeui-app/releases/` не править — обновление заменит его.
- Голос: Groq, ключ в `app.env` (VOICE_API_KEY), после смены — `sudo systemctl restart claudecodeui`.
- Файлы входа в Claude не копировать между папками.
<!-- claude-ui:end -->
```

## Шаг 8. Итоговое сообщение человеку

Коротко и по-человечески, по образцу:

> Готово! Теперь ваш Claude открывается как сайт и как приложение на телефоне.
>
> Что умеет: чаты с Claude с телефона и компьютера; строка «Ход работы» показывает,
> чем Claude занят; обрыв связи не теряет ответ; несколько чатов вкладками;
> голосовой ввод; можно пригласить другого человека (Настройки → приглашения).
> Интерфейс сам обновляется каждую ночь и проверяет обновление перед установкой.
>
> **Что сделать вам:**
> **1. Откройте ссылку <ссылка> и добавьте на экран «Домой».**
> **2. Ссылка — как пароль: никому не пересылайте.**
> **3. Хотите голосовой ввод — пришлите ключ Groq (инструкция выше).**

## Если что-то пошло не так

| Что видно | Что сделать |
|---|---|
| Установщик: «порт 80/443 занят программой …» | Чужой веб-сервер. Не останавливать. Объяснить человеку; вариант — поставить интерфейс за этот сервер вручную, если он настроен тобой же |
| «не выпустился сертификат» | Проверить, открыт ли порт 80 снаружи (файрвол в панели хостинга). Лимит sslip.io и nip.io исчерпан — нужен свой поддомен, `--domain` |
| Сайт открывается, чат не отвечает | Шаг 3: проверить вход в Claude настоящим запросом |
| Микрофон не распознаёт | Нет ключа Groq в `app.env` или ключ отозван: проверить `curl …/models`, при необходимости новый ключ |
| Служба не стартует | `journalctl -u claudecodeui -n 80 --no-pager`; откатиться: `ln -sfn <прежний releases/…> ~/claudecodeui-app/current && sudo systemctl restart claudecodeui` |
| Потеряна ссылка входа | Войти по запасному имени и паролю из `install-summary.txt`; в Настройках выпустить новую ссылку |

**EXECUTE NOW:** выполни шаги 1–8 по порядку, не останавливаясь на технических
вопросах, и закончи, когда человек получил рабочую ссылку, чат ответил, а таймер
обновлений включён.
