# Claude UI — свой Claude как сайт и приложение на телефоне

Веб-интерфейс для Claude Code на вашем собственном сервере. Открывается с
телефона и компьютера, как обычный сайт или приложение на экране «Домой».
Внутри — ваши чаты с Claude, голосовой ввод и видно, над чем Claude работает.

Это доработанная версия открытого проекта
[siteboon/claudecodeui](https://github.com/siteboon/claudecodeui) (лицензия AGPL-3.0),
переделанная под русский язык и iPhone. Ветка `main` — ровно та версия,
которая работает у автора каждый день; она обновляется сама.

---

## Установить себе — одно сообщение

**Что нужно заранее**

- Свой сервер (VPS) на Ubuntu или Debian, от 4 ГБ памяти, и на нём Claude Code.
- Платная подписка Claude — Pro или Max (на бесплатной Claude Code не работает).

**Что сделать**

1. Откройте Claude на своём сервере.
2. Отправьте ему это сообщение целиком:

   > Установи мне веб-интерфейс Claude по инструкции
   > https://github.com/Seikatsuma/claudecodeui/blob/main/INSTALL-FOR-AI.md —
   > прочитай её целиком и сделай всё сам. Мне пиши простыми словами,
   > а что нужно сделать мне — жирным внизу сообщения.

3. Дальше Claude всё сделает сам. От вас понадобится немного, и он напишет это
   жирным внизу сообщения:
   - открыть присланную ссылку и добавить сайт на экран «Домой»;
   - один раз войти в свою подписку Claude, если он попросит;
   - по желанию — получить бесплатный ключ для голосового ввода (5 минут, инструкция ниже).

**Покупать домен не нужно.** Адрес сайта будет бесплатный, вида
`https://12-34-56-78.sslip.io`. Хотите красивый адрес — раздел «Свой адрес» ниже.

## Что умеет

- **Чаты с Claude с телефона.** На iPhone и Android — как приложение: иконка
  на экране «Домой», вход по личной ссылке без пароля, поле ввода не прыгает
  от клавиатуры.
- **«Ход работы».** Одна строка между вашим сообщением и ответом показывает,
  что Claude делает сейчас; раскрывается — видны ключевые мысли по-русски.
- **Чат не теряется.** Обрыв связи, перезапуск сервера или обновление не
  прерывают работу: Claude доделывает ответ, сообщение досылается само.
- **Голосовой ввод.** Нажали микрофон, сказали — получили текст.
- **Вкладки и группы чатов.** Несколько чатов открыты сразу; видно, какой
  из них сейчас думает. Чаты раскладываются по группам и дням, есть поиск по
  названиям и переписке.
- **Командная строка сервера** — ещё одной вкладкой, как чат.
- **Расход подписки** — те же полосы «5 часов» и «неделя», что в самом Claude.
- **Приглашения.** Можно пустить другого человека по ссылке-приглашению —
  у него будут свои, отдельные чаты.

## Голосовой ввод — бесплатно (Groq)

Речь в текст распознаёт сервис Groq (модель Whisper). Бесплатно — примерно до
8 часов записи в сутки, один файл до 25 МБ. Карта не нужна.

1. Откройте **https://console.groq.com** и войдите: проще всего кнопкой Google
   (своя почта Gmail) или по своей электронной почте. Если сайт не открывается —
   включите VPN.
2. Слева **API Keys** → **Create API Key** → любое название → **Submit**.
3. Скопируйте ключ (начинается с `gsk_`) и отправьте его своему Claude на сервере
   со словами «подключи голосовой ввод». Ключ показывается один раз — если
   потеряли, создайте новый.

Тем же ключом Claude может расшифровывать и записи — голосовые, звонки,
встречи. Попросите: «сделай мне расшифровку аудиофайлов тем же ключом Groq».

## Обновления — сами

Каждую ночь сервер сам проверяет, вышла ли новая версия. Если вышла — собирает
её рядом с работающей, прогоняет проверки и только потом переключает.
Не прошла проверку — остаётся прежняя версия, ничего не ломается. Спросить
своего Claude «обновился ли интерфейс?» можно в любой момент.

## Свой адрес вместо sslip.io

Если есть свой домен (или его владелец готов выделить поддомен):

1. В настройках домена добавить запись **A**: имя, например, `asya`, значение —
   IP-адрес вашего сервера (Claude скажет его).
2. Подождать 10–30 минут и написать Claude: «переведи интерфейс на адрес
   asya.example.ru».
3. Открыть новую ссылку входа и заново добавить сайт на экран «Домой».

## Для разработчиков

- `INSTALL-FOR-AI.md` — пошаговая инструкция для ИИ-агента, который ставит интерфейс.
- `deploy/selfhost/install.sh` — установка одной командой (nginx, HTTPS, systemd,
  ночной таймер, владелец и ссылка входа). Повторный запуск безопасен.
- `deploy/selfhost/update.sh` — обновление с проверкой (сборка с проверкой типов,
  тесты сервера против работающей версии, пробный запуск) и откатом.
- Оригинальная документация проекта: [docs/README.md](docs/README.md).
